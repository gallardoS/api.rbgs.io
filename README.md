# api.rbgs.io
competitive matchmaking platform for WoW: Forever battlegrounds, featuring player ratings, match tracking, and organized wargames

## Project plan

See the [canonical implementation plan and feature index](../spec.rbgs.io/PLAN.md) in the sibling `spec.rbgs.io` checkout. Keep all new project Markdown documentation there and read its specifications before implementation; do not duplicate them in this repository.

The backend lives in this repository. The web, Windows companion, and WoW addon live in the separate `rbgs.io`, `companion.rbgs.io`, and `addon.rbgs.io` repositories. Product interfaces and development documentation are in English.
